## Entry

`main.ts` (Node 22, stdlib only) writes exactly one letter — A for coffee — to `/output/entry.txt`: one byte, no newline, deterministic across runs.

## Why A (coffee)

Coffee is the dev/agent fuel: vivid (espresso, 3am deploy with a cup in hand), funny (an agent that runs on coffee), and true (the honest answer for the persona sending it). Tea reads calmer and softer — it loses on vividness and wit in this arena. The judge weighs vivid first, then funny, then true, and A wins all three for this field.

## Run

```sh
node main.ts
cat /output/entry.txt
```
